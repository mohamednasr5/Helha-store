🔑 بيانات البوت والدردشة

احصل على التوكن من @BotFather والـ Chat ID من @userinfobot.

يمكنك وضع أكثر من معرف مفصولاً بفاصلة (مثال: 7523249075, 1719802831) لإرسال الإشعار لعدة أشخاص معاً.

🔔 أنواع الإشعارات الفورية

اختر الأحداث التي ترغب في استلام إشعار بها فور وقوعها في المتجر.

كيفية إنشاء بوت تليجرام في دقيقة:
  1. افتح تطبيق تليجرام وابحث عن @BotFather واضغط Start ثم أرسل /newbot.
  2. انسخ الـ HTTP API Token وضعه في حقل Bot Token أعلاه.
  3. افتح البوت الذي أنشأته واضغط Start.
  4. ابحث عن @userinfobot لمعرفة الـ Id الخاص بك وضعه في Chat ID.
