# متجر حِلها - Helha 🛒💡
> **كل مشكلة ليها حلّها** | "وفّرنا لك كل الحلول والأدوات اللي تسهل حياتك"

متجر إلكتروني متكامل وعصري باللغة العربية (RTL) مع لوحة تحكم إدارية شاملة ومترابطة مع:
- **Firebase Realtime Database** لقاعدة البيانات والتحديثات اللحظية.
- **Cloudflare R2 + Worker** لرفع صور المنتجات والإيصالات وحفظها.
- **Telegram Bot** لإرسال إشعارات فورية بكل طلب أو دخول للوحة التحكم.

---

## 🚀 المميزات الرئيسية للمشروع

### 1. واجهة المتجر (Storefront - `index.html`)
- تصميم عصري وسريع متوافق مع الموبايل والتابلت والكمبيوتر.
- ألوان وهوية مأخوذة من الشعار والغلاف الرسمي (الأخضر البترولي الداكن، الأصفر الخردلي، والمرجاني).
- تصنيفات متعددة (حلول المطبخ، أدوات التنظيف، حلول منزلية، عروض خاصة).
- بحث فوري ذكي وسريع في المنتجات.
- نافذة عرض سريع للمنتج مع أبرز الميزات والمواصفات.
- سلة تسوق جانبية (Slide-Over Drawer) مع شريط تفاعلي لحساب الشحن المجاني.
- نموذج إتمام الطلب (Checkout) وحفظ البيانات فورياً في Firebase وإشعار تليجرام لحظياً.
- رسالة شكر وتتبع برقم الطلب مع زر مباشر للتواصل عبر واتساب.

### 2. لوحة التحكم الإدارية (Admin Dashboard - `admin.html`)
- **حماية تسجيل الدخول:** كلمة مرور مشفرة ومؤمنة في Firebase.
- **إحصائيات مباشرة:** إجمالي الطلبات، إجمالي المبيعات، عدد الزوار، وعدد المنتجات.
- **إدارة المنتجات:**
  - إضافة وتعديل وحذف المنتجات.
  - إمكانية حذف المنتجات أو استعادتها.
  - رفع صور المنتجات مباشرة إلى **Cloudflare R2** عبر Worker مع إمكانية إدخال رابط مباشر.
- **إدارة الطلبات:**
  - عرض تفاصيل كل طلب والعميل والعنوان.
  - زر مراسلة فورية للعميل عبر واتساب بضغطة واحدة.
  - تغيير حالة الطلب (جديد 🔵، قيد التجهيز 🟡، تم الشحن 🚚، مكتمل 🟢، ملغي 🔴).
- **إعدادات بوت التليجرام:**
  - إعدادات الإشعارات الفورية للطلبات والدخول.
- **الأمان والإعدادات العامة:**
  - إمكانية تغيير كلمة مرور لوحة التحكم من داخل اللوحة.

## 🛠️ تفاصيل التشغيل والتقنيات المستخدمة

- **الواجهة:** HTML5, CSS3, Modern JavaScript (Vanilla ES6+).
- **قاعدة البيانات:** Firebase Realtime Database.
- **التخزين السحابي للصور:** Cloudflare R2 + Cloudflare Workers.
- **الإشعارات:** Telegram Bot API.

## 📦 كيفية التشغيل والرفع على GitHub Pages

1. استنساخ المستودع:
   ```bash
   git clone https://github.com/mohamednasr5/Helha-store.git
   ```
2. فتح المشروع محلياً عبر أي خادم ويب محلي (مثل Live Server في VS Code) أو تشغيل `index.html`.
3. لتفعيل الموقع عبر **GitHub Pages**:
   - ادخل إلى إعدادات المستودع في GitHub (**Settings**).
   - اختر من القائمة الجانبية **Pages**.
   - تحت قسم **Build and deployment**، اختر الفرع `main` والمجلد `/(root)`.
   - اضغط **Save** وسيتم نشر الموقع مباشرة.
